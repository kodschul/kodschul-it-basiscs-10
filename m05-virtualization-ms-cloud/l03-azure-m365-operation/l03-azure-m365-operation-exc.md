# Lab 5.3 - Uebung: Testnutzer und Azure-VM nachvollziehen

## Auftrag

In der trainerbereitgestellten Testumgebung einen Testnutzer im M365 Admin Center untersuchen und eine Azure-VM-Konfiguration nachvollziehen. Nur mit ausdruecklicher Freigabe wird ein Testnutzer oder eine Test-VM angelegt.

## Start

Ein Testtenant, ein Testkonto, erlaubte Rollen und ein Budget- beziehungsweise Ressourcenlimit stehen bereit.

## Schritte

1. Im M365 Admin Center einen vorhandenen Testnutzer oeffnen und Nutzername, Lizenz und zugewiesenen Dienst zeigen.
2. Mit Freigabe einen weiteren Testnutzer anlegen oder die vorbereitete Eingabemaske durchgehen.
3. Im Azure-Portal eine vorbereitete VM oeffnen und Groesse, Betriebssystem und Zugriffsweg benennen.
4. Einen vorhandenen Backup- oder Snapshot-Eintrag der VM anzeigen.
5. Im Partnerpaar erklaeren, welche Aufgabe Azure uebernimmt und welche beim Team bleibt.

## Fertig, wenn

- ein Testnutzer mit Dienstzuordnung sichtbar ist,
- drei VM-Einstellungen benannt sind,
- ein Wiederherstellungsartefakt sichtbar ist,
- keine produktiven Nutzer, VMs oder Daten veraendert wurden.

## Hilfe

1. Bei fehlender Berechtigung nur die Trainer-Demo verfolgen.
2. Niemals private oder produktive Zugangsdaten verwenden.
3. Unklare Kosten- oder Loeschdialoge nicht bestaetigen.

## Zusatzaufgabe

Eine passende Regel fuer einen Testnutzer formulieren, etwa zeitlich begrenzte Lizenz oder MFA-Pflicht.
