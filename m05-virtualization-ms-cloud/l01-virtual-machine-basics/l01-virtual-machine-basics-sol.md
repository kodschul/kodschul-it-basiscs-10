# Lab 5.1 - Loesung: Eine lokale Test-VM starten

## Schritt 1: VM anlegen oder importieren

VirtualBox oder Hyper-V oeffnen. Eine neue VM anlegen oder die vom Trainer bereitgestellte Vorlage importieren.

## Schritt 2: Ressourcen waehlen

Name, RAM und virtuelle Festplatte gemaess den Kursvorgaben waehlen. Diese Werte duerfen den Host nicht ueberlasten.

## Schritt 3: Vorlage zuordnen

Das freigegebene Installationsmedium oder die VM-Vorlage zuordnen.

## Schritt 4: VM starten

Die Startfunktion oeffnet ein eigenes VM-Fenster mit Anmeldebildschirm oder Desktop.

## Schritt 5: Trennung erklaeren

Der Host ist der reale Kursrechner. Die VM ist das Gastbetriebssystem im Fenster. Ein Test in der VM betrifft nicht automatisch den Host.

## Zusatzaufgabe

Wenig RAM bedeutet, dass die VM Daten haeufiger auf langsameren Speicher auslagern muss. Dadurch wird sie traeger.
