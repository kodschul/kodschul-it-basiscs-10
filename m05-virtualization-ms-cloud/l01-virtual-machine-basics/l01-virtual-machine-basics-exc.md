# Lab 5.1 - Uebung: Eine lokale Test-VM starten

## Auftrag

Eine vorbereitete lokale Test-VM in VirtualBox oder Hyper-V anlegen, starten und als getrennten Computer erkennen.

## Start

VirtualBox oder Hyper-V ist installiert. Ein freigegebenes Installationsmedium oder eine vorbereitete VM-Vorlage steht bereit.

## Schritte

1. Die Virtualisierungssoftware oeffnen und eine neue VM anlegen oder die Vorlage importieren.
2. Einen Namen vergeben und die vom Trainer vorgegebenen Ressourcen auswaehlen.
3. Das bereitgestellte Installationsmedium oder die Vorlage zuordnen.
4. Die VM starten und den Anmeldebildschirm zeigen.
5. Im VM-Fenster den Host und die VM als zwei getrennte Systeme benennen.

## Fertig, wenn

- die VM in der Virtualisierungssoftware sichtbar ist,
- der Anmeldebildschirm oder Desktop der VM erscheint,
- die getrennte Rolle von Host und Gast erklaert werden kann.

## Hilfe

1. Keine privaten Installationsdateien verwenden.
2. Ressourcen nur in der vom Trainer freigegebenen Groesse vergeben.
3. Startet die VM nicht, zuerst die Vorlage und das Installationsmedium pruefen.

## Zusatzaufgabe

Eine Hardware-Einstellung der VM ansehen und begruenden, warum zu wenig RAM die VM verlangsamen kann.
