# Lab 7.3 - Uebung: KI-Skript erzeugen, ausfuehren und Ethik-Fragen beantworten

## Auftrag

Zwei PowerShell-Skripte per KI-Prompt erzeugen lassen, sie in VS Code ausfuehren und mindestens einen Fehler beheben, danach drei Ethik-Fragen schriftlich beantworten.

## Start

VS Code mit PowerShell-Unterstuetzung und Zugang zur KI-Oberflaeche sind geoeffnet.

## Schritte

1. Einen Prompt formulieren, der ein PowerShell-Skript mit zwei Zahlen-Eingaben und einer Rechnung anfordert.
2. Den erzeugten Code in eine neue Datei `skript1.ps1` in VS Code einfuegen.
3. `skript1.ps1` ausfuehren und das Ergebnis pruefen.
4. Einen zweiten Prompt fuer ein Skript formulieren, das eine Datei anlegt und beschreibt (z. B. Notizen speichern), in `skript2.ps1` einfuegen und ausfuehren.
5. Falls eine Fehlermeldung erscheint: Zeile und Fehlertext lesen, Ursache benennen und das Skript korrigieren.
6. Mindestens eine Zeile in einem der beiden Skripte selbst veraendern (z. B. anderer Text, andere Rechenart) und erneut ausfuehren.
7. Drei Fragen schriftlich beantworten: Wann sollte man KI-generiertem Code nicht blind vertrauen? Welche Daten sollten nicht in einen Prompt eingegeben werden? Sollte offengelegt werden, wenn ein Ergebnis mit KI erstellt wurde - warum/warum nicht?

## Fertig, wenn

- beide Skripte erfolgreich ausgefuehrt wurden,
- mindestens eine Fehlermeldung selbst gelesen und behoben wurde (oder begruendet ist, dass keine auftrat),
- alle drei Ethik-Fragen schriftlich beantwortet sind.

## Hilfe

1. Ein Prompt fuer Code sollte die Sprache (PowerShell) und die genaue Aufgabe nennen.
2. VS Code zeigt Fehlermeldungen meist direkt im Terminal unterhalb des Skripts.
3. Bei Unsicherheit: den fehlerhaften Codeabschnitt der KI erneut mit der Fehlermeldung als Prompt zeigen und um eine Korrektur bitten.

## Zusatzaufgabe

Der KI-Oberflaeche die eigene Fehlermeldung aus Schritt 5 als Prompt schicken und die vorgeschlagene Korrektur mit der eigenen vergleichen.
