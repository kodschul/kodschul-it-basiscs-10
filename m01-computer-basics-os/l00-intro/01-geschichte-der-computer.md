# Geschichte der Computer: Von Rechenhilfen zu vernetzten Systemen

## Leitfragen

<details><summary>Was hat sich an Computern seit den ersten Großrechnern verändert?</summary>

Computer wurden kleiner, schneller, günstiger und stärker vernetzt. Die
Grundaufgaben Berechnen, Speichern, Ein- und Ausgabe blieben erhalten.

</details>

<details><summary>Warum ist das World Wide Web nicht dasselbe wie das Internet?</summary>

Das Internet verbindet Netzwerke. Das World Wide Web nutzt dieses Netzwerk für
Webseiten und Webdienste.

</details>

## Begriffe

| Begriff           | Definition                                                          |
| ----------------- | ------------------------------------------------------------------- |
| Großrechner       | leistungsstarker Computer für viele Aufgaben und Nutzer             |
| Personal Computer | Computer für einen einzelnen Arbeitsplatz                           |
| Internet          | weltweiter Verbund vieler Netzwerke                                 |
| World Wide Web    | Webseiten und Webdienste, die über das Internet erreichbar sind     |
| Cloud             | Rechenleistung, Speicher oder Software als Dienst über ein Netzwerk |
| KI                | Software, die aus Daten Muster ableitet oder Inhalte erzeugt        |
| IoT               | Internet of Things: vernetzte Geräte mit Sensoren oder Aktoren      |

- Computer wurden nicht nur schneller. Sie wurden kleiner, vernetzter und leichter bedienbar.
- Jede Epoche baut auf denselben Grundlagen auf: Daten, Berechnung, Speicherung, Ein- und Ausgabe sowie Kommunikation.
