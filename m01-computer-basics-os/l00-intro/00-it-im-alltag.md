# IT im Alltag: Aufgaben, Rollen und Lernweg

## Leitfragen

<details><summary>Wo begegnet IT im eigenen Alltag?</summary>

IT steckt zum Beispiel in Zahlung, Navigation, Kommunikation, Druck und
Online-Diensten. Entscheidend ist das Zusammenspiel aus Gerät, Software und Daten.

</details>

<details><summary>Welche IT-Rolle hilft bei einer fehlenden Anmeldung?</summary>

Support grenzt die Störung ein. Administration verwaltet Konten und Berechtigungen.
Je nach Ursache arbeiten beide Rollen zusammen.

</details>

## Was bedeutet IT?

| Begriff  | Definition                                 | Beispiel                                  |
| -------- | ------------------------------------------ | ----------------------------------------- |
| IT       | Informations- und Kommunikationstechnik    | Kasse, Website, Anmeldung, Drucker        |
| Daten    | gespeicherte Informationen                 | Name, Bestellung, Bild, Preis             |
| Software | Programme und Anwendungen auf einem Gerät  | Browser, Textverarbeitung, Betriebssystem |
| System   | Teile, die gemeinsam eine Aufgabe erfüllen | Browser, Server und Website               |

## IT-Rollen lösen Probleme

| Situation                           | Rolle          | Typische Aufgabe                               |
| ----------------------------------- | -------------- | ---------------------------------------------- |
| Anmeldung funktioniert nicht        | Support        | Ursache eingrenzen und Zugang prüfen           |
| Website wird benötigt               | Entwicklung    | Anwendung bauen oder anpassen                  |
| Neue Arbeitsplätze entstehen        | Administration | Konten, Geräte und Berechtigungen verwalten    |
| Kundendaten müssen geschützt werden | Security       | Risiken bewerten und Schutzmaßnahmen festlegen |

> **Merksatz:** IT-Fachleute zerlegen Fragen in kleine, prüfbare Schritte.
