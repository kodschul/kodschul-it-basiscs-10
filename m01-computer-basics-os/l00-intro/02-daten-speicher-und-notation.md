# Daten, Speicher und Notation

## Leitfragen

<details><summary>Warum sind Bit und Byte nicht dasselbe?</summary>

Ein Bit hat zwei mögliche Zustände, 0 oder 1. Ein Byte besteht aus 8 Bit und
ist eine größere Einheit für Daten.

</details>

<details><summary>Warum macht mehr Speicherplatz einen Computer nicht automatisch schneller?</summary>

Speicherplatz beschreibt Kapazität. Geschwindigkeit hängt zusätzlich von CPU,
RAM und der Art des Speichers ab.

</details>

## Einheiten für Datenmengen

| Einheit | Bedeutung                               | Beispiel                                      |
| ------- | --------------------------------------- | --------------------------------------------- |
| Bit     | kleinste Information mit zwei Zuständen | 0 oder 1                                      |
| Byte    | Gruppe aus 8 Bit                        | ein einzelnes Zeichen, vereinfacht betrachtet |
| KB      | Kilobyte, etwa 1.000 Byte               | kurzer Text                                   |
| MB      | Megabyte, etwa 1.000 KB                 | Foto oder Musikdatei                          |
| GB      | Gigabyte, etwa 1.000 MB                 | App, Video oder Arbeitsspeicher               |
| TB      | Terabyte, etwa 1.000 GB                 | große Festplatte oder Backup                  |

![USB-Speicherstick als Beispiel für Datenspeicher](https://commons.wikimedia.org/wiki/Special:FilePath/SanDisk-Cruzer-USB-4GB-ThumbDrive.jpg?width=640)

## Zwei Zahlensysteme

| System        | Ziffern | Beispiel für die Zahl zehn |
| ------------- | ------- | -------------------------- |
| Dezimalsystem | 0 bis 9 | `10`                       |
| Binärsystem   | 0 und 1 | `1010`                     |

## Datentypen

| Datentyp    | Bedeutung                          | Beispiel     |
| ----------- | ---------------------------------- | ------------ |
| Text        | Zeichenfolge                       | `Bäckerei`   |
| Zahl        | Wert für Berechnung oder Vergleich | `4,50`       |
| Datum       | Kalenderwert                       | `20.09.2026` |
| Wahr/Falsch | Aussage mit zwei Zuständen         | `wahr`       |
| Bild        | visuelle Daten                     | Produktfoto  |

- Eine Zahl kann Text sein, wenn sie nur gespeichert oder angezeigt wird, etwa eine Kundennummer.
- Mehr Speicherplatz macht einen Computer nicht automatisch schneller. Geschwindigkeit hängt auch von CPU, RAM und Speichertechnik ab.
