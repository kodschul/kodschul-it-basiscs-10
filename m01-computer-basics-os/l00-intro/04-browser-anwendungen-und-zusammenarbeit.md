# Browser, Anwendungen und Zusammenarbeit

## Leitfragen

<details><summary>Ist das Internet dasselbe wie ein Browser?</summary>

Nein. Ein Browser ist eine Anwendung. Das Internet ist der weltweite Verbund
von Netzwerken, über den der Browser Webinhalte anfordern kann.

</details>

<details><summary>Warum bedeutet „geteilt“ nicht automatisch „sicher“?</summary>

Geteilte Inhalte brauchen passende Berechtigungen. Entscheidend ist, wer lesen,
ändern oder weitergeben darf.

</details>

## Anwendungen im Arbeitsalltag

| Begriff                | Definition                                          | Beispiele                              |
| ---------------------- | --------------------------------------------------- | -------------------------------------- |
| Webbrowser             | Anwendung zum Aufrufen und Anzeigen von Webinhalten | Edge, Firefox, Chrome, Safari          |
| Webanwendung           | Anwendung, die im Browser genutzt wird              | Online-Shop, M365, Ticketsystem        |
| Desktop-Anwendung      | Anwendung, die auf dem Gerät installiert ist        | Word, Outlook, Bildbearbeitung         |
| Produktivitätssoftware | Anwendung für typische Arbeitsaufgaben              | Text, Tabelle, Präsentation, Kalender  |
| Kollaborationssoftware | Anwendung für gemeinsames Arbeiten                  | Chat, geteilte Dateien, Videokonferenz |

## Abgrenzung

| Aussage                                | Einordnung                                                                    |
| -------------------------------------- | ----------------------------------------------------------------------------- |
| "Das Internet ist mein Browser."       | Falsch: Der Browser ist eine Anwendung; das Internet ist ein Netzwerkverbund. |
| "Geteilt bedeutet sicher freigegeben." | Falsch: Freigaben brauchen passende Berechtigungen.                           |
| "Eine Webanwendung läuft im Browser."  | Richtig: Teile der Anwendung laufen zusätzlich auf Servern.                   |

- Browser und Webanwendungen werden an Tag 2 sichtbar.
- Produktivitäts- und Kollaborationssoftware wird an Tag 6 mit Microsoft 365 vertieft.
