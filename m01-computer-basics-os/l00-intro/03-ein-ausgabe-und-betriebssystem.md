# Ein- und Ausgabe, Betriebssystem und Anwendungen

## Leitfragen

<details><summary>Ist ein Bildschirm ein Eingabe- oder Ausgabegerät?</summary>

Ein normaler Bildschirm ist ein Ausgabegerät. Ein Touchscreen ist ein Ein- und
Ausgabegerät, weil er Bild ausgibt und Berührungen entgegennimmt.

</details>

<details><summary>Welche Aufgabe hat ein Betriebssystem?</summary>

Es vermittelt zwischen Hardware und Anwendungen. Es organisiert Programme,
Dateien, Geräte und Nutzerrechte.

</details>

## Peripheriegeräte

| Kategorie        | Definition                          | Beispiele                                 |
| ---------------- | ----------------------------------- | ----------------------------------------- |
| Eingabe          | Gerät liefert Daten an den Computer | Tastatur, Maus, Kamera, Scanner, Mikrofon |
| Ausgabe          | Gerät gibt Daten vom Computer aus   | Bildschirm, Drucker, Lautsprecher         |
| Ein- und Ausgabe | Gerät sendet und empfängt Daten     | Touchscreen, Netzwerkkarte, USB-Stick     |

## Software-Schichten

| Begriff        | Definition                                      | Beispiele                                  |
| -------------- | ----------------------------------------------- | ------------------------------------------ |
| Hardware       | anfassbare Technik                              | CPU, SSD, Bildschirm                       |
| Betriebssystem | Grundsoftware zwischen Hardware und Anwendungen | Windows, macOS, Linux                      |
| Anwendung      | Programm für eine konkrete Aufgabe              | Browser, Tabellenkalkulation, Mailprogramm |
| Treiber        | Software für die Kommunikation mit Hardware     | Drucker- oder Grafikkartentreiber          |

- Ein Bildschirm verarbeitet Daten nicht selbst. Er gibt ein Bild aus.
- Eine Datei ist nicht dasselbe wie das Programm, das sie öffnet.
