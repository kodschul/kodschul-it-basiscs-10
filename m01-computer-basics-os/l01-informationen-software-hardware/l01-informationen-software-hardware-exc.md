# Lab 1.1 - Mission: Einen Computer einsatzbereit machen

## Auftrag

Eine kleine Bäckerei richtet einen neuen Kassen-PC ein. Das Team erhält
Bauteil-, Funktions- und Fehlerkarten. Ordnet die Karten so, dass klar wird,
welches Teil welche Aufgabe hat und welches Teil bei einem Problem zuerst
geprüft werden sollte.

## Start

Pro Gruppe liegen bereit:

- Bauteilkarten: CPU, RAM, Mainboard, Netzteil, SSD, HDD, ROM
- Funktionskarten zu allen sieben Bauteilen
- drei Fehlerkarten: "Der PC startet nicht.", "Programme reagieren sehr
  langsam.", "Eine Rechnung soll nach dem Ausschalten noch vorhanden sein."

## Schritte

1. Legt jede Bauteilkarte neben die passende Funktionskarte.
2. Legt RAM, ROM, SSD und HDD als Speicherstrecke aus: kurzfristig oder
   dauerhaft, schneller oder langsamer.
3. Nehmt die Fehlerkarte "Der PC startet nicht." Wählt eine Karte, die
   zuerst überprüft werden sollte, und notiert eine Begründung.
4. Nehmt die Fehlerkarte "Programme reagieren sehr langsam." Wählt eine
   Karte, die dazu passen kann, und notiert eine Begründung.
5. Nehmt die Fehlerkarte zur Rechnung. Wählt einen passenden dauerhaften
   Speicher und begründet die Wahl.
6. Jede Gruppe stellt mindestens eine ihrer drei Fehlerkarten-Entscheidungen
   im Plenum vor. Die anderen Gruppen prüfen die Begründung mit den
   Funktionskarten und stellen bei Unklarheit eine Rückfrage.
7. Mini-Check: Jede Person zeigt auf einem Bild zwei Bauteile und nennt ihre
   grobe Aufgabe (siehe `Fertig, wenn`).

## Fertig, wenn

- alle sieben Bauteile einer Funktion zugeordnet sind,
- die vier Speicherarten sichtbar eingeordnet sind,
- zu jeder Fehlerkarte eine begründete Entscheidung vorliegt,
- jede Gruppe mindestens eine Entscheidung im Plenum vorgestellt hat und
  jede Person im Mini-Check zwei Bauteile korrekt benennen kann.

## Wenn ihr nicht weiterkommt

1. Was passiert, wenn der Strom weg ist: Bleibt die Information erhalten?
2. Muss das Bauteil rechnen, aktuelle Daten bereithalten oder dauerhaft
   speichern?
3. Vergleicht die Entscheidung mit dem Wasser-Eimer-Modell im Handout.

## Zusatzaufgabe

Eine Grafikkarte und ein CPU-Kühler kommen als neue Karten hinzu. Entscheidet,
ob der Kassen-PC ohne sie sinnvoll arbeiten kann, und begründet die Antwort.

Eine gedruckte oder digitale Kartenansicht liefert dasselbe Ergebnis.
