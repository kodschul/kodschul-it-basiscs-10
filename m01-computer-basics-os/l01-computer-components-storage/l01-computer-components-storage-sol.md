# Lab 1.1 - Lösung: Einen Computer einsatzbereit machen

## Schritt 1: Bauteil und Funktion

| Bauteilkarte | Funktionskarte                                                |
| ------------ | ------------------------------------------------------------- |
| CPU          | rechnet Programmbefehle                                       |
| RAM          | hält aktuell gebrauchte Daten bereit, verliert sie ohne Strom |
| Mainboard    | verbindet alle Bauteile                                       |
| Netzteil     | liefert Strom                                                 |
| SSD          | speichert dauerhaft, schnell                                  |
| HDD          | speichert dauerhaft, mechanisch/langsam                       |
| ROM          | speichert dauerhaft, meist nur lesbar                         |

## Schritt 2: Speicherstrecke

RAM ist kurzfristiger Arbeitsspeicher und verliert seinen Inhalt ohne Strom.
ROM, SSD und HDD behalten ihren Inhalt. Für die alltägliche Einordnung gilt:
RAM arbeitet am schnellsten, SSD ist deutlich schneller als HDD. ROM ist
klein und enthält meist feste Startinformationen, deshalb ist es kein Ersatz
für SSD oder HDD.

## Schritt 3: Der PC startet nicht

Das Netzteil ist eine passende erste Prüfung, weil ohne Stromversorgung kein
Bauteil arbeiten kann. Auch das Mainboard kann beteiligt sein, weil es die
Verbindungen herstellt. Die Fehlerkarte verlangt keine eindeutige Diagnose,
sondern eine fachlich begründete erste Prüfung.

## Schritt 4: Programme reagieren sehr langsam

RAM ist die passende Karte. Ist zu wenig Arbeitsspeicher frei, muss das
Betriebssystem Daten auf den langsameren dauerhaften Speicher auslagern.
Dadurch reagiert der Rechner deutlich träger.

## Schritt 5: Die Rechnung bleibt erhalten

SSD oder HDD sind richtig, weil beide dauerhaft speichern. Für einen neuen
Kassen-PC ist eine SSD die naheliegende Wahl: Sie ist schneller und hat keine
beweglichen Teile. RAM ist falsch, weil sein Inhalt beim Ausschalten verloren
geht.

## Schritt 6: Entscheidung prüfen

Eine Entscheidung gilt als nachvollziehbar, wenn die Gruppe das Bauteil mit
seiner Aufgabe begründet. Bei "PC startet nicht" sind mehrere erste
Prüfpunkte möglich, bei langsamen Programmen und dauerhafter Speicherung
sind RAM beziehungsweise SSD/HDD die erwarteten Antworten. Jede Gruppe stellt
mindestens eine Entscheidung vor; die anderen Gruppen dürfen mit den
Funktionskarten gegenprüfen und nachfragen.

## Schritt 7: Mini-Check

Zwei beliebige Bauteile aus CPU, RAM, Mainboard, Netzteil, SSD, HDD oder ROM
werden korrekt benannt, wenn Name und grobe Aufgabe (rechnen, kurzfristig
bereithalten, verbinden, Strom liefern, dauerhaft speichern) genannt werden
können — die exakte Fachformulierung ist nicht erforderlich.

## Hinweis

Diese Zuordnung vereinfacht bewusst: reale Systeme kennen zusätzlich Caches
(L1/L2/L3) zwischen CPU und RAM, die hier nicht Teil des Lernziels sind.
