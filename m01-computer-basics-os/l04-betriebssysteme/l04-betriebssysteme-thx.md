# Modul 1: Bausteine eines Computersystems & Betriebssysteme

## Lab 1.4 – Betriebssysteme

---

**Ziel:** Erklären, was ein Betriebssystem leistet, und Windows, macOS und
Linux anhand typischer Merkmale unterscheiden.

Ein Betriebssystem ist die Grundsoftware, die zwischen Hardware und den
Anwendungen vermittelt, die wir täglich benutzen.

**Leitfragen:**

<details>
<summary>Was macht ein Betriebssystem eigentlich?</summary>

Es vermittelt zwischen Hardware und Programmen: Programme fragen beim
Betriebssystem an, wenn sie z. B. eine Datei speichern oder etwas anzeigen
wollen, statt direkt mit der Hardware zu sprechen.

</details>

<details>
<summary>Warum kann nicht jedes Programm einfach direkt auf die Hardware zugreifen?</summary>

Ohne Betriebssystem müsste jedes Programm selbst wissen, wie genau jede
Tastatur, jeder Bildschirm und jede Festplatte angesprochen wird. Das
Betriebssystem übernimmt diese Vermittlung einmal zentral für alle Programme.

</details>

<details>
<summary>Was unterscheidet Windows, macOS und Linux voneinander?</summary>

Alle drei sind Betriebssysteme mit denselben Grundaufgaben. Sie unterscheiden
sich in Bedienung, Lizenzmodell (kostenpflichtig vs. quelloffen) und
typischem Einsatzgebiet (Privat-PC, Server, Kreativ-Arbeitsplatz).

</details>

---

## Was ist ein Betriebssystem?

| Begriff        | Definition                                      | Beispiel                                  |
| -------------- | ----------------------------------------------- | ----------------------------------------- |
| Betriebssystem | Grundsoftware zwischen Hardware und Anwendungen | Windows, macOS, Linux                     |
| Anwendung      | Programm für eine konkrete Aufgabe              | Browser, Textverarbeitung, Bildbetrachter |
| Hardware       | anfassbare Teile eines Computers                | Tastatur, SSD, Bildschirm                 |
| Nutzerrecht    | erlaubte Aktion einer Person                    | Datei lesen oder ändern                   |

## Aufgaben des Betriebssystems

| Aufgabe                         | Beispiel                                  |
| ------------------------------- | ----------------------------------------- |
| Programme starten und verwalten | mehrere Fenster gleichzeitig offen halten |
| Dateien organisieren            | Ordnerstruktur und Dateisystem            |
| Hardware ansprechen             | Tastatur, Maus, Bildschirm, Netzwerkkarte |
| Nutzerrechte verwalten          | festlegen, wer lesen oder ändern darf     |

## Verbreitete Betriebssysteme

| Betriebssystem | Definition                                     | typischer Einsatz                   |
| -------------- | ---------------------------------------------- | ----------------------------------- |
| Windows        | weit verbreitetes Betriebssystem von Microsoft | Privat-PCs, Büroarbeitsplätze       |
| macOS          | Betriebssystem von Apple für Mac-Geräte        | Kreativ-Arbeitsplätze, Apple-Geräte |
| Linux          | quelloffenes, frei anpassbares Betriebssystem  | Server, Cloud, Container            |

- Windows und macOS sind kostenpflichtig und an bestimmte Hersteller gebunden.
- Linux ist quelloffen (Open Source) und läuft auf sehr unterschiedlicher Hardware.
- Server und Container (siehe Lab 1.6) laufen sehr häufig mit Linux, ganz ohne
  grafische Oberfläche.

## Fazit

- Das Betriebssystem vermittelt zwischen Hardware, Programmen und Nutzern.
- Es startet Programme, organisiert Dateien und verwaltet Rechte.
- Windows, macOS und Linux erfüllen dieselben Grundaufgaben, unterscheiden
  sich aber in Lizenz, Bedienung und typischem Einsatzgebiet.
