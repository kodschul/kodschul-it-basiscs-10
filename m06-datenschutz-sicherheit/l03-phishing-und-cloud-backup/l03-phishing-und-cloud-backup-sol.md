# Lab 6.3 - Loesung: Phishing-Mails erkennen und Backup einordnen

## Schritt 1-3: Mails bewerten

| Mail | Entscheidung | Merkmal                                                                     |
| ---- | ------------ | --------------------------------------------------------------------------- |
| 1    | Phishing     | Absenderdomain weicht leicht vom echten Namen ab                            |
| 2    | echt         | passende Absenderadresse, keine Dringlichkeit, korrekte Anrede              |
| 3    | Phishing     | Linktext zeigt "Anmelden", Linkziel fuehrt zu einer fremden Domain          |
| 4    | Phishing     | starke Dringlichkeit ("Konto wird gesperrt"), Aufforderung zur Dateneingabe |
| 5    | echt         | bekannter interner Absender, kein Link, keine Handlungsaufforderung         |

## Schritt 4-5: Cloud-Backup

```text
OneDrive/SharePoint: Ordner "baeckerei-test" anlegen
Testdatei hochladen
Versionsgeschichte oder Papierkorb oeffnen -> vorherige Version/Datei ist wiederherstellbar
```

## Schritt 6: Vergleich im Partnerpaar

Am schwierigsten sind meist die Faelle, die einen bekannten internen Anlass vortaeuschen (z. B. Mail 4), weil die Dringlichkeit von der Pruefung ablenkt.

## Zusatzaufgabe

Eine eigene Beispielmail sollte mindestens zwei Merkmale kombinieren, z. B. eine leicht abweichende Absenderadresse und eine Dringlichkeitsformulierung ("nur heute gueltig").
